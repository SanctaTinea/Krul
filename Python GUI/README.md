# Starset — Krul Control Panel

## Тестирование без платы

GUI принимает как обычные имена COM-портов, так и URL-транспорты pyserial.
Чтобы запустить Python-симулятор, выполните в этом каталоге:

```powershell
python krul_simulator.py
```

В поле `Порт` GUI вручную введите `socket://127.0.0.1:7000` и нажмите
`Подключить`. Скорость для TCP не используется. Симулятор поддерживает
discovery, stateful GPIO, виртуальный ADC, echo, log events и задержанные
ответы. Режим stdin/stdout доступен через `python krul_simulator.py --stdio`.
Среди входов есть `SQUARE_2S`: он выдаёт прямоугольный сигнал, переключаясь
между `LOW` и `HIGH` каждую секунду (полный период — 2 секунды).

Симулятор СПУ повторяет таблицу команд прошивки `Apps/app_cm7/src/app_cmd.c`
(те же `tab`, `group`, `order`, схемы параметров и результата). Запуск:

```powershell
python spu_simulator.py
```

Он слушает `socket://127.0.0.1:7001`. `WHOAMI` сообщает устройство `СПУ`,
команда `READ_TELEMETRY` возвращает массив `nodes` из тегированных объединений
«телеметрия / событие», а Starset рисует их прямо по схеме `DESCRIBE`, без
`widget_hint`. Режим stdin/stdout доступен через `python spu_simulator.py --stdio`.

Автоматические headless-тесты используют fake transport и не открывают сокет:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Нативный сервер на настоящих C-библиотеках serde/Krul собирается из корня
репозитория preset-ом `PC_Debug` и по умолчанию слушает порт 7001:

```powershell
cmake --preset PC_Debug
cmake --build --preset PC_Debug
.\build\PC_Debug\Tools\krul_host_server.exe
```

Для него в GUI укажите `socket://127.0.0.1:7001`. В Developer Command Prompt
для Visual Studio команды CMake сразу видят MSVC; в обычном PowerShell сначала
нужно активировать среду MSVC. Сервер также поддерживает `--stdio` и
`--port PORT`.

GUI работает с контроллерами Krul v4 через transport framing v1 и не содержит списка
проектных команд. После подключения он выполняет `WHOAMI`, `CMD_LIST` и
`DESCRIBE` для каждой команды. Обычные команды с командным `widget_hint`
`special_gpio` отображаются специализированной GPIO-панелью внутри общего
построителя команд. Такая панель соблюдает метаданные `tab`, `group` и `order`,
а имя вкладки не получает отдельный префикс `IO`. В `Starset.py` вкладка
«Кролик вампир» дополнительно объединяет формы и GPIO-панели со всех
тематических вкладок. Команды, в описании которых присутствует
`"nogui": true`, не создают форм, специализированных панелей или вкладок, но
остаются доступны в raw JSON-терминале.

После discovery Starset раз в секунду отправляет минимальный built-in `PING`;
его успешный ответ содержит только `id` и `success`, без `result`. Флаг `PING`
в нижней панели временно отключает и отправку, и контроль ответов, одновременно
сбрасывая счётчик пропусков. Enum-поля показывают `title` из `DESCRIBE`, но во
всех форматах передают исходный числовой `value`.

В режиме разработчика появляется флаг `Показывать NoGUI`. Он позволяет
временно вывести обычные формы скрытых служебных команд, не меняя полученные
от контроллера дескрипторы.

### Расширение виджетов Starset

`Starset.py` использует три реестра, ключами которых являются значения
`widget_hint`, а значениями — классы обработчиков:

- `PARAM_WIDGETS` — входные поля; класс наследует `ParameterWidget` и реализует
  `value()`;
- `RESULT_WIDGETS` — поля результата; класс наследует `ResultWidget` и
  реализует `setValue()`;
- `COMMAND_WIDGETS` — целые команды; класс наследует `CommandWidget` и получает
  весь список дескрипторов с одинаковым hint.

Каждый класс проверяет совместимость через `validate_descriptor()` или
`validate_descriptors()` и выбрасывает `WidgetCompatibilityError` с причиной
отказа. Starset выводит её в терминал и строит стандартную форму. Поэтому новый
виджет добавляется отдельным классом и одной записью в соответствующем реестре,
без изменения `CommandForm` или `MainWindow`.

## Запуск

Starset автоматически сохраняет пользовательские коэффициенты ADC-виджетов и
настройки графиков в `Starset/profiles.json` внутри системного каталога
конфигурации приложения. Профиль выбирается по `device_id` из `WHOAMI`; для
старых устройств без этого поля используется общий профиль модели по
`device_name` и `protocol_version`. COM-порт и версия прошивки в ключ профиля
не входят.

В PowerShell из каталога `Python GUI`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe Starset.py
```

Существующее виртуальное окружение нельзя переносить между компьютерами:
`pyvenv.cfg` и launchers содержат абсолютный путь к исходному Python. Если
`.venv` была скопирована и не запускается, удалите её вручную и создайте заново
командами выше.

Каждый UART/TCP-кадр начинается с `KRJ1`, `KRB1` или `KRC1`, содержит `uint32` длину
payload, один JSON/BSON/CBOR object Krul и CRC-16/CCITT-FALSE. Codec выбирается рядом
со скоростью порта до подключения; JSON используется по умолчанию. GUI назначает
transaction ID от 1 до `4294967295`, сопоставляет ответы независимо от порядка
и отдельно обрабатывает асинхронные сообщения с полем `event`. Событие `log`
с полями `severity` и `message` отображается в терминале соответствующим цветом.

В режиме разработчика Starset показывает накопленные за текущее подключение
счётчики TX/RX и длительность соединения. TX учитывает полный transport frame
с заголовком и CRC, RX — все реально прочитанные из serial/TCP байты.

## Графики реального времени

Кнопка `Графики` в `Starset.py` открывает отдельное окно `GrathPlot`. Список
каналов строится автоматически из числовых и логических полей `result` каждого
DESCRIBE-дескриптора; вложенные `object` разворачиваются, а величины показываются
по вкладкам, группам и командам.

Доступны два режима: несколько величин от времени и выбранные величины Y от
другой величины X. Команды с метаданными `autoupdate` GrathPlot может опрашивать
сам с заданным периодом (с учётом `min_period`/`max_period`). Результаты остальных
команд также попадают на график, когда пользователь выполняет их в основном
окне. Окно поддерживает паузу, очистку данных, фильтр каналов и ограничение
видимого временного интервала. Для всех серий можно включать и скрывать маркеры
точек, а также выбирать сплошные, штриховые, точечные, штрих-пунктирные линии или
оставлять только точки.

Обычный автоопрос Starset и автоопрос графика используют один ожидающий запрос
на команду. При совместной работе применяется наиболее частый из двух циклов,
а запрос выполняется с текущими параметрами обычной формы. Поэтому данные не
дублируются и результаты разных наборов параметров не смешиваются.

GrathPlot сохраняет результаты всех каналов независимо от их видимости. Буфер
удерживает данные на длительность выбранного окна, но не менее 30 секунд, и
ограничен консервативно рассчитанным объёмом 1 ГиБ. Старые кадры удаляются
первыми. После повторного включения линии временной или X/Y-график сразу
восстанавливается из сохранённых кадров. Дополнительные Python-зависимости не
требуются.

Кнопка `Сохранить изображение` записывает текущий холст вместе с осями, легендой
и выбранным оформлением в PNG, JPEG или BMP. `Экспорт CSV` сохраняет весь
актуальный буфер, включая скрытые каналы, в широкую таблицу UTF-8 с BOM. Первые
колонки содержат локальную ISO-временную метку и секунды от начала накопления,
остальные колонки именуются уникальными ключами `КОМАНДА:путь.поля`. Кадры, в
которых конкретная команда не обновляла величину, содержат пустую ячейку.
Checkbox `Объединять цикл в CSV` собирает соседние ответы разных каналов в одну
строку с временной меткой первого ответа. Повторное появление уже добавленного
канала считается началом следующего цикла. Режим не заполняет отсутствующие
измерения старыми значениями, поэтому редкие или пропущенные ответы всё ещё могут
оставлять отдельные пустые ячейки.

У каждой конечной величины в дереве есть компактные поля `Множитель` и `База` со
значениями `1` и `0` по умолчанию. График использует формулу
`отображаемое = исходное × множитель + база`, а CSV всегда содержит исходные
сырые значения без этих преобразований. В буфере также сохраняются исходные
значения, поэтому коэффициенты можно менять после накопления данных: временные и
X/Y-линии немедленно пересчитываются без повторного опроса контроллера. Поля
коэффициентов сделаны компактными, заголовок дерева имеет контрастное оформление,
а цвет закрепляется за ключом величины и не меняется при добавлении или временном
скрытии других линий.

Входные пины, созданные виджетом `special_gpio`, дополнительно регистрируются в
GrathPlot во время выполнения и отображаются как логические величины `0`/`1`.
Выходные пины в этот список не добавляются. Одинаковые GPIO-панели на обзорной и
тематической вкладках считаются одним источником. При включённом общем автоопросе
Starset график использует уже получаемые им ответы; при выключенном общем
автоопросе выбранные GPIO-линии может опрашивать таймер самого GrathPlot.
На временном графике GPIO отображаются не ступенчатой линией, а событиями:
реальное изменение состояния создаёт вертикальную пунктирную отметку. Стрелка
вверх обозначает переход в `HIGH`, стрелка вниз — переход в `LOW`; первое
прочитанное состояние и повторные ответы без изменения маркер не создают. В
режиме X/Y GPIO остаётся обычной величиной `0`/`1`, поскольку ось времени там
отсутствует. События участвуют в масштабе временной оси X, но не расширяют
диапазон Y обычных графиков.
